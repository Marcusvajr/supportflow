# `.opencode`

Diretório reservado para os comandos, regras, skills e workflows gerados pelo OpenSpec para o OpenCode.

A inicialização local prevista no roteiro é:

```powershell
openspec init --tools antigravity,opencode
```

O arquivo `opencode.json` na raiz contém a configuração de provider/MCP utilizada pelo SupportFlow. Credenciais reais permanecem no `.env` local.
